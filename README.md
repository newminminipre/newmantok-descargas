# NewmanTok: descargas

Aquí se publican los instaladores de **NewmanTok**, la app de escritorio para streamers de TikTok LIVE (subastas, ruletas, alertas y overlays).

- Para descargarla y ver cómo instalarla: https://newmantok.vercel.app/descargar
- Las apps instaladas buscan aquí sus actualizaciones.
- Este repositorio solo guarda instaladores: aquí no hay código.
